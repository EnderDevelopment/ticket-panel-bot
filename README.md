# Ticket Panel Bot

A Discord bot that allows server admins to create customizable ticket panels with buttons, text, and images.

## Features

- Create customizable ticket panels
- Add images to ticket panels
- Change button text

## Requirements

- Python 3.8 or higher
- discord.py
- python-dotenv
- python-dateutil
- pytz

## Installation

1. Clone the repository
2. Install the required packages: `pip install -r requirements.txt`
3. Create a `.env` file based on `.env.example` and add your Discord bot token
4. Run the bot: `python bot.py`

## Usage

1. Invite the bot to your Discord server
2. Use the `/ticket` command to create a ticket panel
3. Customize the ticket panel with the desired button text and image URL

## Configuration

- `DISCORD_TOKEN`: Your Discord bot token
